# Terra-IQ

**Enterprise GIS Workspace for Land Intelligence, Parcel Management, and Real Estate Analytics**

Terra-IQ is a modern web-based Geographic Information System (GIS) designed for real estate companies, surveyors, land professionals, and property developers. It combines interactive mapping, parcel intelligence, spatial analysis, and project management into a single platform.

---

## Key Features

- 🗺️ Interactive GIS Workspace
- 📍 Parcel Intelligence & Analysis
- 🏘️ Project Portfolio Management
- 📊 Dashboard & Analytics
- 📑 Reservation Management
- 👥 Customer Management
- 🌍 Interactive Leaflet Mapping
- 🛣️ Road Network Integration
- 🏥 Nearby Services Analysis (Schools, Hospitals, Towns)
- 📄 Downloadable Land Documents
- 🗄️ PostgreSQL + PostGIS Backend
